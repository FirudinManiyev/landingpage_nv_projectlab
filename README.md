# Firudin Maniyev — Şəxsi Portfolio

Bu, yalnız **HTML** və **CSS** ilə hazırlanmış sadə bir one-page landing page-dir.
Heç bir framework, kitabxana və ya JavaScript istifadə olunmayıb.

---

## 📂 Qovluqdakı fayllar

| Fayl          | Təyinatı                          |
|---------------|-----------------------------------|
| `index.html`  | Səhifənin strukturu (semantik HTML) |
| `style.css`   | Səhifənin bütün üslubları          |
| `README.md`   | Bu sənəd                          |

---

## 🚀 Necə istifadə etməli

1. `index.html` faylını hər hansı bir brauzerdə açın (Chrome, Firefox, Edge və s.).
2. Heç bir quraşdırma, build və ya server tələb olunmur.

---

## ✨ Xüsusiyyətlər

- ✅ Yalnız **HTML5** və **CSS3** (JavaScript yoxdur)
- ✅ Semantik etiketlər: `header`, `nav`, `main`, `section`, `footer`
- ✅ Mobil, планşет və desktop üçün **responsive** dizayn
- ✅ Sticky header və smooth scroll naviqasiya
- ✅ CSS ilə hazırlanmış avatar (şəkil faylı tələb etmir)
- ✅ Sade və modern görünüş

---

## 🎨 İstifadə olunan əsas rənglər

Rəngləri dəyişmək üçün `style.css` faylının əvvəlindəki `:root` blokundakı
dəyişənləri redaktə edin:

- Əsas rəng (göy-bənövşəyi): `#6366f1`
- Vurğu rəng (çəhrayı): `#ec4899`
- Fon: `#fafaf9`
- Mətn: `#111827`

---

## 📝 Məzmunu necə dəyişməli

- **Adı dəyişmək** — `index.html` faylında `Firudin Maniyev` mətnini axtarın.
- **Email və ya şəhər** — `index.html` faylının altındakı `footer` blokunu redaktə edin.
- **Naviqasiya linkləri** — `index.html` faylındakı `<nav>` hissəsindəki `<li>` elementlərini dəyişin.
- **Rəngləri dəyişmək** — `style.css` faylının əvvəlindəki `:root` blokundakı `--color-*` dəyişənlərini redaktə edin.
